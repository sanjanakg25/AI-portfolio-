# Sanjana K G · Personal portfolio

A static portfolio covering experience, publications, talks, and education. Built with HTML and CSS, with no build step or JavaScript dependency.

The visual design matches [Venkat Reddy’s portfolio](https://venkat-rj.github.io/): the same typeface, page width, colors, headings, profile layout, and experience timeline.

## Preview locally

Run `python3 -m http.server 4174` in this directory and open http://localhost:4174.

## Publish with GitHub Pages

A repository administrator can open **Settings → Pages**, select **Deploy from a branch**, and choose **main / (root)**, then save.

The expected address after publishing is https://sanjanakg25.github.io/AI-portfolio-/.

All asset links are relative, so the site works under the repository path.

## Content

Edit `index.html` to update the profile and `style.css` for appearance. Content is based on the supplied résumés, with public links for publications and the World Machine Learning Summit talk. Selected work was carried out at Continental; it is not presented as public source code.

The Inter font is bundled with its license in `assets/Inter-LICENSE.txt`. The Continental logo identifies the employer; it is not an endorsement. No analytics or third-party scripts are included.
