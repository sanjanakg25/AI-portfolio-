Selected work

A selection of the projects I’ve worked on at Continental.

Engineering document understandingOngoing

I’m building a system to process engineering documents using eight or more specialized agents. I use LangGraph to coordinate tasks such as identifying headings, splitting document content, and extracting metadata. Azure Document Intelligence and PyMuPDF help me extract information from page layouts, images, and tables.

I combine text and image context to check cross-references and interpret information across a document.

Semantic search and evaluation

I developed a semantic-search API that embeds queries, retrieves information from two document collections, and reranks the results. I also built an evaluation framework to assess retrieval quality.

SQL question answering and web retrieval

I’m developing a chatbot that uses Claude Sonnet and database schema information to turn questions into SQL queries. In a separate project, I built a web-fetching MCP server and a Gradio interface for answering questions with live web information, using LangChain MCP adapters and Azure OpenAI.

Supplier selection and material optimization

I applied genetic algorithms to supplier selection and material utilization, extending optimization workflows in pymoo to account for requirements from different teams. I also co-authored research on incorporating user priorities into supplier selection with NSGA-III.

Other projects at Continental

  • Powered tailgate components. I used sensor data from vehicle control units to model the condition of the gas springs in electric power liftgates.
  • Duplicate material records. I built an application to identify and resolve duplicate records in material data, with experts reviewing the results. I also automated 95% of the pipeline that extracted, transformed, and loaded the data, and created Power BI reports. Project details.
  • Stock levels across plants. I analyzed inventory data to understand which factors were associated with changes in stock levels at different plants.
  • Hose aging. I studied how the elastic properties of hoses changed as they aged. I used the findings to guide what data to collect next.
  • Vehicle tracking and arrival times. I used vehicle diagnostic data and machine learning to develop systems for tracking vehicles and estimating their arrival times.
  • Employee exit clearance. I used UiPath to automate steps in the HR clearance process when an employee leaves the company.
