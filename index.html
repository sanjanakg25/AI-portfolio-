At Continental, I develop machine-learning systems for engineering teams. My work has grown from modeling automotive components and optimizing supplier choices to building search and language-model systems.

  • Information retrieval and evaluation. I built a semantic-search API that retrieves and reranks results from two document collections, along with an evaluation framework to measure retrieval quality and guide improvements. Search project.
  • Document understanding. I’m building a system that brings together text, figures, and tables from complex engineering PDFs. It uses specialized agents to interpret document structure and check references across the content. Ongoing work.

Alongside these projects, I’ve trained around 200 colleagues in data science and AI adoption and conducted optimization workshops for engineering teams.

Earlier work in automotive and manufacturing data
  • Predicting component health. I developed a model to predict gas-spring health in powered vehicle tailgates using sensor data from the vehicle’s electronic control unit.
  • Duplicate material records. I built an application to identify and resolve duplicate records in material data, with experts reviewing the results. I also automated 95% of the pipeline that extracted, transformed, and loaded the data, and created Power BI reports. Project details.
  • Understanding inventory levels. I used time-series analysis, regression, and random-forest feature importance to identify factors associated with stock levels across manufacturing sites.
  • Measuring material degradation. I investigated how hose materials change as they age, using noise, vibration, and changes in elastic properties. I developed methods to quantify degradation and used the findings to guide further data collection.
  • Vehicle tracking and arrival times. I used vehicle diagnostic data and machine learning to develop systems for tracking vehicles and estimating their arrival times.
  • Employee exit clearance. I used UiPath to automate steps in the HR clearance process when an employee leaves the company.

Projects

Reading engineering documents In progress

I’m building a system that reads text, tables, and images in engineering documents. It identifies headings, breaks the content into sections, and checks references between different parts of a document.

Finding information in documents

I built a search API that finds relevant information across two document collections and ranks the results. I also built an evaluation framework to check how well the search works.

Asking questions about data In progress

I’m building a chatbot that turns questions into SQL queries using the structure of a database. In a separate project, I built a question-answering interface that can fetch information from the web.

Comparing suppliers

I used genetic algorithms to compare supplier choices against several requirements at once. I also co-authored a paper on incorporating user priorities into that comparison.

Technical details
  • Document processing. I coordinate eight or more agents with LangGraph, using Azure Document Intelligence and PyMuPDF for layout, image, table, and metadata extraction.
  • Search. My API uses query embeddings, retrieval across two corpora, and reranking, with an evaluation framework for retrieval quality.
